# Gap playbook

The next step for each layer when it's rated none or partial in a high-risk area. Replace {harm area} with the area in question.

## Policy

- [ ] Write a clear rule for {harm area}, with internal guidelines, examples and edge cases reviewers can apply.

Related tool: [Stress-test the rule](https://stevenmacchia.github.io/ts-workbench/#policy)

## Detection

- [ ] Add proactive detection for {harm area}, such as hash matching, classifiers or behavior signals, so you don't rely on user reports.

Related tool: [See safeguards in a pre-mortem](https://stevenmacchia.github.io/ts-workbench/#premortem)

## Enforcement

- [ ] Train reviewers on {harm area}, define the actions they can take, and set service levels by severity.

Related tool: [Score moderation vendors](https://stevenmacchia.github.io/ts-workbench/#vendors)

## Appeals

- [ ] Let users appeal {harm area} decisions, with a second reviewer and a response target.

Related tool: [Try the appeal reviewer](https://stevenmacchia.github.io/ts-workbench/#appeal)

## Measurement

- [ ] Track prevalence, time to action and accuracy for {harm area}, and review them with leadership.

Related tool: [Build your scorecard](https://stevenmacchia.github.io/ts-workbench/#metrics)
